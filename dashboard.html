Server Setup Required

The trading agent runs a local Python server. Follow these steps to get started:

  1. Get free Alpaca paper trading API keys at alpaca.markets (sign up → Paper Trading → API Keys)
  2. Copy and fill in credentials:
    cd trading_agent && cp .env.example .env
    Edit .env with your Alpaca keys, then pick an LLM: Anthropic API key, or set LLM_PROVIDER=local for a local Ollama model.
  3. Install dependencies:
    pip install -r requirements.txt
  4. Start the server:
    python server.py
  5. Refresh this page — the dashboard will connect automatically.
